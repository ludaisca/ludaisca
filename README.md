# Luis Islas

Construyo software de negocio en México: CRM multicanal, facturación CFDI y automatización con IA.

## En lo que trabajo

| Proyecto | Qué resuelve |
| --- | --- |
| **Colibly** | CRM conversacional multi-tenant para vender por WhatsApp, Instagram, Messenger, Telegram y webchat, con bots de IA, campañas y cobro recurrente. |
| **Factzi** | Emisión de CFDI 4.0 desde la foto de un ticket: OCR, automatización de los portales de cada comercio y timbrado. |
| **RPA / task mining** | Captura nativa en Windows para decidir con datos qué tareas manuales conviene automatizar. |
| **Argos** | Agente autónomo de investigación en Facebook e Instagram. |

## Herramientas

`TypeScript` · `Python` · `PostgreSQL` · `Next.js` · `Fastify` · `Prisma` · `Playwright` · `Docker` · `Redis`

## Público

- **[argos](https://github.com/ludaisca/argos)** — agente de investigación en Facebook e Instagram: CLI, Docker y despliegue con Coolify.
